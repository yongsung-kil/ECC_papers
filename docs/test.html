Confluence 렌더링 호환성 테스트

브라우저 창과 Confluence 창을 나란히 띄우고, 항목마다 같은 모습인지 견줍니다.

각 항목의 초록색은 그 기법이 살아있다는 뜻이고, 빨간색이나 회색은 Confluence가 지웠다는 뜻입니다. 지워진 기법은 앞으로 쓰지 않습니다.

먼저 알아둘 것
T09, T10, T11, T12 는 바깥 인터넷에 나가는 항목입니다. 사내망에서 막히면 Confluence 탓이 아니라 망 정책 탓일 수 있습니다. 브라우저 창에서도 실패하면 망 문제이고, 브라우저 창에서만 통과하면 Confluence가 지운 것입니다.
T09, T10 은 이 저장소의 GitHub Pages 주소를 부릅니다. Pages가 아직 게시 전이면 두 창 모두 실패로 나옵니다.

A군. 지금 의심하고 있는 항목

style 블록, class, 자바스크립트, position, 외부 리소스, flex와 grid

T01
style 블록
통과하면 초록색 굵은 글씨, 실패하면 검은 보통 글씨입니다.
style 블록 안의 규칙이 먹혔습니다
T02
class 속성만으로 꾸미기
통과하면 초록색 굵은 글씨에 초록 테두리, 실패하면 맨 글씨입니다. class 속성이 남아있어도 style 블록이 지워지면 실패합니다.
class 로만 지정한 색과 테두리
T03
class 와 인라인 style 을 함께 걸었을 때
인라인이 이기면 파란색입니다. 초록색으로 보이면 class 쪽이 이긴 것이고, 그건 Confluence CSS가 우리 인라인을 덮어쓸 수 있다는 뜻이므로 위험 신호입니다.
파란색이면 인라인 우선, 초록색이면 class 우선
T04
문서 안에 쓴 script 태그

여기를 눌러 보십시오
T06
position: absolute
회색 상자의 오른쪽 위 구석에 초록 딱지가 붙어 있으면 absolute 가 살아있습니다. 딱지가 왼쪽 아래로 흘러내렸거나 상자 밖으로 나갔으면 죽은 것입니다.
오른쪽 위 구석
T07
